How to Use
1️⃣
Select a Controller Tier
Pick Starter, Standard, Professional, or Enterprise based on how many access controllers your deployment manages (e.g. 50 / 500 / 2,000+).
2️⃣
Choose a Service Configuration
Minimum = cost-optimized dev/test SKUs. Standard = balanced production. Advanced = zone-redundant enterprise HA. Costs update instantly.
3️⃣
Adjust the Sliders
Tune heartbeat interval, credential events, and alarm events to match your expected traffic. These drive Cosmos DB and SQL Alarm cost calculations.
4️⃣
Toggle Reservations, Add-Ons & Support
Enable 1-Year Reservations for a ~35% discount on eligible services. Choose a Failover scope, DR tier, and any Optional Add-Ons (backups, peak throughput).
5️⃣
Review the Summary & Breakdown
The Summary shows monthly and annual totals. The Service Breakdown table itemizes every Azure service with its SKU and cost, and the bar chart shows spending by category.
6️⃣
Export or Print
Click Export to Excel to download a formatted spreadsheet, or Print for a formatted PDF. Use Reset to return all settings to the Standard defaults.
All prices are West US estimates re-verified against the Azure Retail Prices API (June 2026). Outbound egress bandwidth is included in all totals. An estimated tax rate can be applied via the Tax Rate field — negotiated enterprise discounts and region-specific pricing are not included. Always validate against the official Azure Pricing Calculator before committing to a budget.

Glossary
AKS (Azure Kubernetes Service)
Microsoft's managed container orchestration platform. Runs the Parabit microservices (access control, alarms, comm, etc.) without requiring you to manage the underlying virtual machines. Cost depends on the number and size of nodes.
Alarm Event
A security alarm triggered by a controller (door forced open, duress, tamper, etc.). Higher alarm rates increase Cosmos DB and SQL Alarm Mgmt costs because each event is stored and indexed.
App Gateway WAF_v2
Azure Web Application Firewall — the secure entry point for all HTTPS traffic from controllers and admin dashboards. Protects against OWASP top-10 attacks. Billed as a flat capacity unit fee per month.
App Service
Azure's managed web hosting platform. Runs the Parabit portal and REST APIs without managing servers. Tier (B2 / S2 / P3v3) controls CPU, memory, and auto-scale capability.
Archive Storage
The lowest-cost Azure Blob tier ($0.00099/GB/mo). Used for data older than 12 months in the retention model. Retrieval takes hours and incurs extra fees — best for compliance-driven cold storage.
Azure Functions
Serverless compute that runs short-lived tasks (event processing, scheduled jobs) without a dedicated server. Billed per execution; near-zero cost at low volumes.
Blob Storage
Azure's object storage for raw files, backups, and archived event data. Three access tiers — Hot, Cool, Archive — with decreasing cost and increasing retrieval latency.
Controller
A physical access control hardware unit (door reader, panel, elevator controller, etc.) managed by the Parabit Cloud platform. Controller count is the primary cost driver — it determines the tier and scales Cosmos DB, SQL Alarm, and egress costs.
Cool Storage
Mid-tier Azure Blob storage ($0.01/GB/mo). Used for data 1–12 months old. Lower cost than Hot but incurs a per-GB retrieval fee. Good for data you access occasionally.
Cosmos DB
Azure's globally distributed NoSQL database. Stores high-volume, low-latency event data: heartbeats, credential scans, and alarm events. Cost is driven by throughput (RU/s) and storage. The Log Mgmt microservice runs on Cosmos DB.
Credential Event
A door access attempt — badge swipe, PIN entry, mobile credential tap, etc. Logged to Cosmos DB and processed by the Comm Service. Higher credential event rates increase database throughput costs.
Disaster Recovery (DR)
Tooling that restores service after a full regional failure — the primary site goes down and compute must be rebuilt in a secondary region. DR provides the runbooks and backups to do this. Contrast with Geo-Failover, which keeps a live secondary always ready.
DTU / eDTU
Database Transaction Unit — Azure SQL's blended measure of CPU, memory, and I/O capacity. eDTU is the elastic-pool equivalent (shared across databases). Higher DTU = more concurrent queries handled. S1 = 20 DTU, S3 = 100 DTU, P1 = 125 DTU.
Egress (Outbound Bandwidth)
Data leaving Azure to the internet (controller status updates, API responses to client apps). First 5 GB/month is free; thereafter $0.087/GB at West US. Scales with controller count and heartbeat frequency.
Elastic Pool
A shared Azure SQL resource (eDTU budget) used by multiple databases. The seven lightweight Parabit microservices (Site Mgmt, Access Point Mgmt, Login Mgmt, Device Mgmt, Encryption Mgmt, License Mgmt, Job Scheduler) share a single elastic pool, reducing cost vs. individual databases.
Entra ID (formerly Azure AD)
Microsoft's identity platform. Used for admin user authentication, single sign-on, and role-based access control. Free tier covers most deployments; P1 license adds conditional access and MFA for regulated environments.
Geo-Failover (Active Geo-Replication)
An always-on secondary deployment in a second Azure region. If the primary region fails, traffic switches in under 30 seconds with near-zero data loss (RPO ≈ 0). More expensive than DR because the secondary runs 24/7. Selected via the Failover Configuration selector.
Heartbeat Interval
How often each controller checks in with the cloud (default: every 1 hour). Shorter intervals (e.g., 10 seconds) dramatically increase Cosmos DB throughput and egress costs because every controller sends a message each cycle.
Hot Storage
The highest-performance Azure Blob tier ($0.0208/GB/mo). Used for the most recent 30 days of event data. No retrieval fees — optimized for frequent access.
Key Vault
Azure's managed secret store. Holds API keys, database connection strings, TLS certificates, and encryption keys. Billed per operation; cost is minimal at platform scale.
Log Analytics
Azure Monitor's log store. Retains platform telemetry, security events, and audit trails beyond the default 30 days. Extended retention (31–730 days) costs $0.10/GB/mo; archive tier (730+ days) costs $0.026/GB/mo.
LTR (Long-Term Retention)
A SQL Database feature that stores weekly, monthly, or yearly backup snapshots in RA-GRS Blob storage for up to 10 years. Used to meet HIPAA, SOX, and ISO 27001 data retention mandates beyond the standard 7–35 day PITR window.
PITR (Point-in-Time Recovery)
SQL Database's ability to restore any database to any second within the retention window (7 days standard, up to 35 days with the backup add-on). Protects against accidental deletion or corruption.
Reservation (1-Year)
A pre-purchase commitment for Azure compute resources (VMs, SQL, App Service) in exchange for a ~35% discount vs. pay-as-you-go. Billed upfront or monthly. The break-even point vs. on-demand is typically 7–8 months. Only eligible services receive the discount.
RPO (Recovery Point Objective)
The maximum acceptable data loss measured in time. RPO = 0 means zero data loss (synchronous geo-replication). RPO = 1 hour means up to 1 hour of transactions could be lost in a failure.
RTO (Recovery Time Objective)
The maximum acceptable downtime from failure to full service restoration. RTO <30s = near-instant failover (geo-replication). RTO 4h = service is restored within 4 hours using DR tooling.
RU (Request Unit)
Cosmos DB's normalized unit of throughput — one RU represents the cost of reading a 1 KB item. Write operations cost more (typically 5× a read). Heartbeats cost ~5 RU each; alarm events cost ~10 RU. Total RU/s determines provisioning cost.
Service Configuration
The SKU and sizing level selected for all Azure services simultaneously. Minimum uses the cheapest viable SKUs (dev/test). Standard uses production-grade balanced SKUs. Advanced uses high-availability, zone-redundant, enterprise-grade SKUs.
SLA (Service Level Agreement)
Microsoft's contractual uptime guarantee. AKS Uptime SLA ($73/mo) guarantees 99.99% API server availability. Without it, AKS offers a best-effort 99.5% target with no financial backing.
SQL Elastic Pool
See Elastic Pool.
Tier (Controller Tier)
The four deployment scales: Starter (1–50 controllers), Standard (51–500), Professional (501–2,000), Enterprise (2,000+). The tier drives the baseline SKU sizes and cost ranges across all services.
